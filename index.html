Internship Application Assistant

A personal, resume-aware tool that I use in my daily workflow to generate honest, tailored internship applications from job descriptions.

The system analyzes job descriptions, matches them with my resume, selects an appropriate application template, and optionally refines the language using a lightweight LLM — with safe fallbacks.

How it works

  • Reads job descriptions (JD)
  • Matches relevant skills & projects from resume
  • Auto-selects a cover letter template
  • Optionally improves wording using Gemini

Usage

This is a command-line tool. To use it locally: 

python main.py
